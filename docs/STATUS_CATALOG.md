# Каталог статусов и состояний портала

**PORTAL-001.3 — discovery, 2026-10-26**

**Статус документа:** частичный каталог. Это не подтверждённый справочник именно статусов отчёта.

## Вывод

- **CONFIRMED:** код `39` присутствует в справочнике workflow-состояний как **«Есть претензия»**. Это не точное подтверждение названия **«Претензия клиента»**.
- **CONFIRMED:** этот справочник используется для workflow predicates на уровне визита/action; опубликованный лист `Статусы проектов` агрегирует количества визитов по проектам. Он не является таблицей статусов отдельных отчётов.
- **UNKNOWN:** полный официальный каталог `report.status_id`, статусы возврата тайному покупателю и переходы report-level.
- **BLOCKED:** live-сверка отдельного отчёта в портале и PostgreSQL-справочника в этом исследовании не выполнена. Доступный в репозитории portal auth-контракт требует POST для создания сессии/токена, а задача запрещает POST; PostgreSQL read-only connection не обнаружено среди доступных OpenWork capabilities.

## Обязательные разграничения

1. **Статус проекта ≠ состояние визита ≠ статус отчёта.** Название листа `Статусы проектов` отражает project-level агрегирование состояний визитов, а не текущий project status и не report status.
2. Код `39` подтверждён как строка справочника **«Есть претензия»**, но не как персональная ошибка корректора и не как доказательство причинности. Претензия может быть связана с ТП, инструкцией, проектом, клиентским толкованием или другим фактором.
3. Код `38` означает **«Вопрос координатору»**. Он не подтверждает отправку замечаний тайному покупателю.
4. Код `35` означает **«Анкета отклонена»**. Без проверенной семантики и примера нельзя приравнять его к «возвращена ТП на замечания».
5. В `report_reviewers.source_status` значение `CURRENT` означает свежесть/результат чтения поля корректора сборщиком, а не завершение проверки отчёта и не report workflow status.

## Источники и открытые вопросы

- `src/workflow_analytics.py` — набор кодов и названий.
- `src/parsers.py` — извлечение цифровых кодов состояния из action-link rows; произвольные числа не считаются статусами.
- `src/acquisition.py` — membership содержит project_id, visit_id, workflow_state_code и action_id; дата перехода/actor отсутствуют.
- `docs/REPORT_CORRECTORS.md` — рабочая модель `/action/{id}` для поля корректора и файловой даты; это не справочник report statuses.
- В `JustForBusy` `portal/data/DATA_MODEL.md` (main, прочитан 2026-10-26) полный каталог visit/report statuses и история названы критическими неизвестными.

**Нужно подтвердить отдельно:** report-level `status_id` и label; код/событие замечаний ТП; точный смысл «Есть претензия»; состояние завершённой проверки; источник и временную семантику каждого статуса.
